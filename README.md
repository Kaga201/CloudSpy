# CloudSpy

## Overview

CloudSpy is a cloud security monitoring and analysis platform designed to simulate how modern cloud environments can be continuously monitored for security risks and vulnerabilities. The project was inspired by the growing adoption of AI in cybersecurity, particularly in threat detection, cloud monitoring, and automated security analysis.

Many cloud security incidents occur due to misconfigurations, weak access controls, and exposed resources rather than sophisticated cyberattacks. CloudSpy aims to address these issues by providing a centralized platform that monitors cloud environments, identifies potential threats, and delivers actionable security insights.

The system combines cloud security monitoring, AI-assisted analysis, digital twin visualization, and website scanning capabilities to help users understand and improve their security posture.

---

## Key Features

### Dashboard Overview

Provides a centralized view of system status, security posture, and threat summaries.

### Threat Scanner

Detects potential cloud security risks from scanned resources and collected data.

### Identity & Access Monitoring

Analyzes user permissions and identifies access control weaknesses.

### Continuous Monitoring Engine

Performs ongoing security assessments and simulated cloud monitoring.

### Alert Center

Displays detected vulnerabilities, warnings, and security notifications.

### AI Engine

Generates intelligent security insights and recommendations based on scan results.

### Scan History

Stores historical scan records for tracking and auditing purposes.

### Web Data Memory

Maintains scanned information for future reference and faster processing.

### Website Link & File Scanner

Scans URLs and uploaded files to identify suspicious patterns and potential security threats.

## Challenge

Develop a platform capable of monitoring cloud environments for security vulnerabilities while providing intelligent analysis and visualization of potential risks.

Key challenges included:

* Designing a realistic cloud security monitoring workflow without direct integration with AWS, Azure, or GCP.
* Integrating multiple modules such as the scanner engine, dashboard, alert system, and digital twin visualization.
* Synchronizing backend scan results with frontend components in real time.
* Reducing false positives generated by rule-based threat detection.
* Resolving authentication issues, including CSRF-related login problems.
* Managing Prisma schema migrations and database connectivity.
* Delivering a complete full-stack solution within a limited hackathon timeframe.

---

## Approach

To address these challenges, CloudSpy was developed using a modular full-stack architecture.

### Threat Detection

A rule-based security engine was created to analyze scanned data and identify common cloud security risks such as:

* Open ports
* Weak IAM permissions
* Public storage exposure
* Suspicious files
* Malicious URL patterns

### Continuous Monitoring

A monitoring engine continuously evaluates system status and generates alerts when risks are detected.

### Digital Twin Visualization

A simulation layer was implemented to represent cloud infrastructure components visually, enabling users to better understand relationships between resources and security issues.

### AI-Assisted Analysis

The system includes an AI integration layer designed to work with Google Gemini API. While the current prototype primarily demonstrates rule-based analysis, the architecture supports future AI-powered recommendations and automated security assessments.

### Security-First Design

Authentication and authorization mechanisms were implemented using JWT and bcrypt to ensure secure user access and account protection.
